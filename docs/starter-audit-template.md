## 90-Day Roadmap

A high-level plan to move from your current state to a stronger AI foundation.

### Phase 1: Foundation (Days 1–30)

**Focus:** Get the basics right before adding AI.

- [ ] Complete Quick Wins 1–3 (see above)
- [ ] Document top 5 core processes
- [ ] Consolidate data into a central location
- [ ] Designate internal AI lead
- [ ] Audit current tools for unused AI features

**Outcome:** You have clean data, documented processes, and someone in charge. The building blocks are in place.

---

### Phase 2: Pilot (Days 31–60)

**Focus:** Test AI on one real use case.

- [ ] Select one process from Phase 1 to automate or assist with AI
- [ ] Choose and trial one AI tool relevant to that process
- [ ] Set a measurable goal (e.g. "reduce time on X task by 30%")
- [ ] Run the pilot for 3 weeks, track results
- [ ] Document what worked and what didn't

**Outcome:** You have real data on what AI does and doesn't do for your business. Not theory — actual results.

---

### Phase 3: Expand (Days 61–90)

**Focus:** Apply learnings and build momentum.

- [ ] Review pilot results with your team
- [ ] Decide: scale this use case, or pivot to a better one?
- [ ] Identify 2–3 additional processes worth the same treatment
- [ ] Set a 6-month AI roadmap based on what you've learned
- [ ] Consider whether external support would accelerate Phase 2 of growth

**Outcome:** You've moved from "wondering about AI" to "making AI decisions based on evidence." That's the shift.
