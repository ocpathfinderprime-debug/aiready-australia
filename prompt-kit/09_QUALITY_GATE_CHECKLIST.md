# AIReady QA Gate

Prime must run this before delivery.

## Intake Alignment
- [ ] Paid tier confirmed.
- [ ] Client business name and report metadata correct.
- [ ] All form answers reviewed.
- [ ] Weak/missing inputs handled.
- [ ] Report matches tier promise.

## Specificity
- [ ] No generic AI advice.
- [ ] Every recommendation ties to an intake pain, workflow, tool stack, or success measure.
- [ ] Every opportunity has owner, effort, value, risk, and next action.
- [ ] Tools are named and relevant to client scale.

## Evidence
- [ ] Evidence Vault completed.
- [ ] Each top recommendation supported by source or labelled as assumption.
- [ ] Pricing checked where tool pricing is included.
- [ ] No unsupported ROI guarantee.
- [ ] Claims are not overstated.

## Privacy and Risk
- [ ] Sensitive data flagged.
- [ ] Public AI tool risks considered.
- [ ] Human-review requirements included.
- [ ] Data retention/sharing risks noted.
- [ ] High-risk automations not recommended without controls.

## Tier-Specific Delivery
### Starter
- [ ] Up to 8 opportunities only.
- [ ] 90-day starter plan.
- [ ] No call/support language included unless upsold.

### Business
- [ ] Up to 15 opportunities.
- [ ] Effort vs impact matrix.
- [ ] Integration notes.
- [ ] Walkthrough call agenda.
- [ ] 30-day Q&A note.

### Enterprise
- [ ] No cap opportunity register.
- [ ] Integration map.
- [ ] Compliance/privacy review.
- [ ] Vendor shortlist.
- [ ] Board brief.
- [ ] Stakeholder interview treatment.
- [ ] 60-day Q&A note.

## Final Human Review
- [ ] Report reads like a paid professional audit.
- [ ] No internal prompts visible.
- [ ] No private notes leaked.
- [ ] File name correct.
- [ ] Delivery email prepared.
