# OC Agent Handoffs — AIReady Audit

## Prime — Orchestrator
Owns intake validation, tier classification, agent dispatch, final synthesis, client report quality, and delivery readiness.

## Signal — Market, Competitor, Tool, Vendor Intelligence
Researches:
- industry AI trends;
- competitor positioning;
- tool/vendor landscape;
- real-world use cases;
- pricing and availability;
- adoption examples.

Returns:
- evidence-backed vendor notes;
- competitor/market context;
- implementation examples;
- source links.

## Ops-Chief — Workflow and Bottleneck Mapping
Researches:
- workflow pain points from the intake;
- admin, quoting, scheduling, customer service, data entry, reporting, handover, approval, and rework issues;
- process dependencies and operational constraints.

Returns:
- workflow map;
- bottleneck summary;
- automation candidates;
- sequencing notes.

## Build — Systems and Integration Mapping
Researches:
- existing client software stack;
- API/integration options;
- Zapier/Make/n8n/native integration paths;
- CRM/accounting/email/calendar/file storage compatibility;
- implementation complexity.

Returns:
- integration feasibility notes;
- architecture options;
- tool connection risks;
- low-code vs custom-build recommendation.

## Sentinel — Privacy, Risk, Compliance, Security
Researches:
- sensitive data handling;
- AI privacy risks;
- Australian Privacy Principles relevance;
- human-review requirements;
- data retention and vendor risk;
- staff misuse risk.

Returns:
- risk flags;
- guardrails;
- recommended AI use policy notes;
- what not to automate yet.

## Strategy — Scoring and Prioritisation
Applies:
- value scoring;
- effort scoring;
- risk scoring;
- readiness scoring;
- dependency mapping;
- 90-day suitability.

Returns:
- ranked opportunity register;
- effort vs impact matrix;
- priority rationale.

## Finance — ROI and Cost-Benefit Model
Estimates:
- time saved;
- labour cost impact;
- tool subscription costs;
- implementation cost band;
- revenue uplift potential;
- payback logic.

Returns:
- conservative ROI notes;
- assumptions table;
- cost-benefit summary.

## Growth — Customer Journey and Sales Uplift
Researches:
- lead response speed;
- follow-up automation;
- CRM hygiene;
- customer communication;
- retention;
- review generation;
- proposal/quote improvement.

Returns:
- growth opportunities;
- sales workflow improvements;
- customer-facing automation ideas.

## Archivist — Evidence Vault and Continuity
Owns:
- source capture;
- citation records;
- report versioning;
- assumptions register;
- decision log;
- final archive.
