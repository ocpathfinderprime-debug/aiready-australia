# Stage 6 Go/No-Go Gate

## Gate A — staging technical readiness

- Runtime builds without blocking TypeScript errors.
- Database migrations apply cleanly to staging.
- RLS prevents cross-tenant data access.
- API health endpoint and telemetry are live.
- MCP read-only tools pass authentication tests.
- OC Prime bridge can emit dry-run events.

## Gate B — public website readiness

- Homepage V6 and priority service pages are live.
- Schema graph validates.
- Sitemap is submitted.
- Robots policy permits intended search and AI-search crawling.
- Page speed and accessibility meet launch threshold.
- Claims are checked against the claim register.

## Gate C — pilot delivery readiness

- Audit methodology is frozen for the pilot cohort.
- Report QA checklist is mandatory.
- Refund, support and escalation paths are defined.
- Customer consent and data handling steps are clear.

## Gate D — commercial readiness

- Pricing is approved.
- Payment and invoice path is tested.
- Sales scripts and objections are complete.
- Support knowledge base is live.
- First case study template is ready.
