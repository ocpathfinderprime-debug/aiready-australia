# North Star Metrics

## Primary metric

**Qualified audit opportunities created per month** from Australian and global target markets.

## Supporting metrics

- Free readiness score completion rate
- Free score to paid audit conversion rate
- Paid audit gross margin
- Average time to deliver report
- Report QA pass rate
- Customer implementation-intent score
- AI citation presence rate across target prompts
- Number of pages cited by AI answer engines
- Partner-sourced qualified leads
- Renewal / implementation sprint attach rate

## Guardrail metrics

- Refund rate
- Report revision rate
- Support escalation rate
- Privacy incident count
- MCP tool error rate
- Cross-tenant access event count
- Unapproved claim count
