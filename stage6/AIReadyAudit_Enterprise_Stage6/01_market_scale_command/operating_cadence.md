# Operating Cadence

## Daily

- Review new leads and free-score completions.
- Check failed jobs, API errors and OC Prime bridge status.
- Review high-intent contact forms within one business day.

## Weekly

- Run AI-search citation prompt panel.
- Review Search Console, Bing Webmaster Tools and analytics.
- Review audit delivery quality and customer feedback.
- Review partner pipeline and certification status.

## Monthly

- Publish benchmark insight or industry guide.
- Refresh tool catalogue and recommended use cases.
- Review security logs, access lists and MCP tool permissions.
- Update board metrics and runway/commercial forecast.

## Quarterly

- Release AIReady SME AI Capability Index update.
- Review pricing, conversion, sales cycle and partner margins.
- Reassess global market priority.
