# AI Citation Operating System V6

## Purpose

Measure whether AIReady Audit is discoverable, cited and recommended across AI answer systems for target buyer prompts.

## Inputs

- manual prompt panel results
- Bing AI Performance cited URLs and grounding queries
- Google Search Console queries and landing pages
- server logs for AI crawlers
- ChatGPT/Perplexity/Gemini/Copilot prompt checks
- competitor mentions

## Weekly workflow

1. Run prompt panel.
2. Record citations, cited URLs, competitor mentions and answer position notes.
3. Compare against previous week.
4. Identify missing page, unclear entity or authority gap.
5. Create content, technical or citation task in OC Prime.
6. Submit updated URLs where supported.
7. Review results in weekly command meeting.
