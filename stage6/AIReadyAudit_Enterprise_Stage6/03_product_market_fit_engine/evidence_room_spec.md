# Evidence Room Specification

## Purpose

Allow customers to securely provide context for audits without exposing unnecessary sensitive information.

## Evidence types

- workflow descriptions
- software/tool list
- anonymised screenshots
- process documents
- sample customer enquiries
- staff role summaries
- current AI usage notes

## Controls

- file type restrictions
- malware scanning
- retention policy
- tenant isolation
- audit access logs
- customer deletion request path
