# Benchmark Index Skill

## Purpose

Aggregate anonymised readiness data into benchmark insights.

## Procedure

1. Confirm scope and tenant context.
2. Gather only approved inputs.
3. Apply the Stage 6 methodology.
4. Produce structured outputs.
5. Flag assumptions, risks and required approvals.
6. Emit OC Prime events where applicable.

## Quality bar

- Evidence-linked findings
- No unsupported guarantees
- Clear next step
- Human review for customer-facing paid outputs
