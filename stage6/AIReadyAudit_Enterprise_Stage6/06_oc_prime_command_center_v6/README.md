# OC Prime Command Center Integration V6

## Integration principle

AIReady Audit is a product module in the OC Prime app mesh. It emits structured events, receives approved commands and exposes dashboard-ready status without giving uncontrolled write access to other apps.

## Main event routes

- lead events → sales queue
- readiness score events → qualification dashboard
- audit workspace events → delivery queue
- QA events → approval queue
- citation events → search visibility dashboard
- partner events → channel dashboard
- incident events → operations dashboard
