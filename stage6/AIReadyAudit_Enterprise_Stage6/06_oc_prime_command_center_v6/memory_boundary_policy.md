# OC Prime Memory Boundary Policy

## Rule

Cross-app memory must use the minimum useful context.

## Allowed by default

- tenant ID
- event type
- non-sensitive status
- aggregate metrics
- redacted summaries

## Approval required

- personal contact details
- uploaded evidence
- report drafts
- customer-specific tool recommendations
- financial details
- partner contract data

## Never share without explicit approval

- credentials
- private customer documents
- sensitive personal information
- raw prompts containing customer secrets
